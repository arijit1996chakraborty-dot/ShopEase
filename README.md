# ShopEase – AI-Powered E-commerce Application

Welcome to ShopEase! This is an AI-powered e-commerce application built using Python, Streamlit and NVIDIA AI.

## 🚀 Live Demo

[Click here to open ShopEase](https://shopease-hyn7xkmoefcsxwajdnhq8f.streamlit.app/)

## Features

- Product catalogue
- Product search and filtering
- Shopping cart
- AI Shopping Assistant
- Simulated checkout
- Order history

## Technologies Used

- Python
- Streamlit
- NVIDIA AI API
- GitHub
